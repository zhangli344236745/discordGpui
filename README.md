# discordGpui

用 **Rust + gpui-kit** 手写的一个 Discord 风格桌面 IM 界面。

目标是把 Discord 桌面端的界面与交互完整复刻一遍：不复用任何现成 UI 框架的皮肤，所有布局、弹层、菜单、状态都在这套代码里显式实现。**纯前端 Demo，数据为内存中的模拟数据，没有后端、没有持久化**，但分层刻意做成可替换结构，方便日后接真实 API。

## 界面布局

```text
+--------+----------------+--------------------------+---------------+
| Rail   | Channels / DMs | Chat                     | Members       |
+========+================+==========================+===============+
| [1]    | TEXT CHANNELS  | # general                | ADMIN - 3     |
| [2]    |   # general    |   topic + tools          |   Nova        |
| [3]    |   # frontend   |   ---------------------  |   Kai         |
|        | VOICE          |   messages (grouped)     | MODERATOR - 2 |
| [@]    |   voice room   |   ---------------------  |   Lin         |
| [o]    |                |   composer: @mention     | ONLINE - 4    |
+========+================+==========================+===============+
| user bar: avatar / name / status / mic / headphones / settings     |
+----------------------------------------------------------------------+
```

服务器栏底部还有两个独立入口：**私信主页**（好友 + 会话列表）与**探索页**（发现并加入公开服务器）。

| 服务器日程 | 标题栏日历图标打开右侧面板：按「即将开始 / 进行中 / 已结束」筛选（带计数），可新建活动（标题 / 描述 / 分类 / 落地频道 / 开始偏移 / 时长）、报名或取消、删除；按服务器隔离，活动随快照持久化 |

### 好友与私信

- 好友页五个标签：**在线 / 待处理 / 全部 / 已屏蔽 / 添加好友**
- 待处理请求可接受（加入好友列表并移除请求）或拒绝，重名会拦截
- 添加好友：`用户名#标签` 输入 → 发送 → 自动跳到待处理标签
- 好友行可屏蔽，屏蔽后进「已屏蔽」分组，可取消屏蔽
- **好友分组**（全部标签）：默认「一起打游戏 / 现实朋友 / 同事 / 未分组」，标题显示人数与在线数，点击折叠；右上「新建分组」，分组右键或行尾省略号可重命名 / 上移 / 下移 / 删除（删除后成员回到未分组）；好友行文件夹按钮可移动到任意分组
- 私信侧栏真实搜索（过滤会话 + 好友 + 发起新对话），点好友即建会话并切入
- **消息请求**：侧栏「消息请求」入口带待处理角标，右侧面板按「待处理 / 已接受 / 已忽略」筛选（带计数）；卡片可「接受」（真正建立私信会话并切入）、「忽略」（不再提醒）、「删除」，请求表随快照持久化
- 私信语音 / 视频通话：DM 标题栏或资料卡的电话 / 摄像头按钮发起，呼叫面板可「模拟接通」，接通后支持麦克风、摄像头、屏幕分享与挂断；跨会话与设置页保持，与服务器语音频道互斥（画面为演示占位）

### 成员

- 成员栏按角色分组（管理员 / 版主 / 贡献者 / 在线 / 离线），分组顺序跟随角色表，可折叠、成员数实时统计；显示服务器昵称，没设置时回退原名
- 点成员或消息作者 → 右侧资料卡（头像、状态、角色、简介、一键「发消息」）
- **右键成员** → 上下文菜单：查看资料卡、发送私信、在输入框提及、复制用户名、屏蔽 / 取消屏蔽

### 语音

- 点语音频道即连接，底部状态条常驻（跨视图保持），再点断开
- 状态条点击展开**语音房间面板**：自己与 3 位参与者、逐个静音 / 移出、本机麦克风开关、断开
- 频道 / 分类 / 服务器被删除时语音状态与参与者列表一并清理

### 探索页

- 服务器栏底部指南针进入，整屏浏览公开服务器
- 关键词搜索 + 分类 chips（游戏 / 科技 / 设计 / 音乐 / 学习 / 影视 / 全部）
- 「加入」后服务器直接出现在左侧栏并自动进入，已加入的卡片显示「已加入」

### 设置

**用户设置**（底部齿轮，9 个分类）：账户（可改显示名称 / 用户名 / 邮箱 / 关于我 / 头像色）、隐私与安全、外观、声音与视频、通知、文字与图片、快捷键、语言、数据与存储（快照路径 / 内容规模 / 立即保存 / 恢复示例数据）。
含主题模式选择、各开关、音量加减、恢复默认；`show_timestamps` / `show_emoji` / `compact_messages` 会真正影响消息渲染。

**服务器设置**（服务器菜单 → 服务器设置，8 个分类）：
- **概览**：改名（消息记录与分类折叠状态自动迁移）、改简介、6 色徽标切换
- **角色**：列表 + 详情（改名 / 6 色切换 / 点成员行授予或移除角色 / 新建 / 删除，改名会同步成员与成员栏分组）
- **权限**：角色 tabs + 分组权限清单（通用 / 文字 / 语音 / 高级 13 项），每行三态按钮循环切换「继承 / 允许 / 拒绝」；角色改名同步权限归属、删除清记录；变更写入审核日志
- **自动审核**：规则列表 + 详情（新建 / 启用停用 / 拦截或警告动作 / 关键词增删），在服务器频道发消息时真实命中关键词——「拦截」阻止发送并保留草稿、「警告」照常发送并提示；命中提示条可关闭，切会话自动清除；规则与审核日志进快照
- **表情**：移除 / 恢复服务器表情
- **邀请**：选频道 / 有效期 / 次数上限 → 生成并复制链接；已创建列表可逐条复制、撤销，失效状态（已过期 / 已用完）自动标红
- **成员**：搜索 + 角色筛选（带人数）→ 改服务器昵称（留空即清除）、移出服务器、封禁；封禁列表可逐条撤销
- **审核日志**：改名 / 改色 / 建删频道 / 角色与成员变更 / 邀请与表情操作自动记录，按类别筛选（带条数）、相对时间倒序、一键清空；最多保留最近 200 条

## 快速开始

环境要求：**macOS** + Rust 工具链（2024 edition，需 1.85+）。

```bash
git clone https://github.com/zhangli344236745/discordGpui.git
cd discordGpui
cargo run
```

首次构建需要编译 gpui 全家桶，耗时较长；之后增量构建在 10 秒内。

窗口固定为 1440×900，标题 `Discord UI · GPUI Kit`，默认深色主题。

```bash
cargo check   # 类型检查，保持 0 error / 0 warning
cargo build   # 完整构建
```

> 本机 `rustfmt` 未安装，`cargo fmt` 会报 `cargo-fmt is not installed`；需要格式化先 `rustup component add rustfmt`。

## 设计要点

**分层与依赖方向**

```text
main → app → data
        ↓
       ui（各视图 render 函数）
```

- `data/` 纯模型，不引用 `app` 或 `ui`，可直接替换为真实 API 响应
- `app.rs` 集中所有状态与业务方法（改状态 + `cx.notify()`），视图只读状态、调方法
- `ui/` 每个模块导出一个 `pub fn render(app, cx)`，不持有自身状态

**状态与视图的边界**：写操作一律是 `DiscordApp` 上的动词方法（`send_message` / `select_channel` / `toggle_*` / `open_*`），视图里不出现字段变更逻辑。这样每个交互都是「视图发出 → app 改状态 → 重渲染」的单向闭环。

**浮层统一约定**：菜单类用绝对定位卡片 + 全屏透明遮罩（点外部关闭），锚点分「跟随光标」与「贴标题栏」两种；模态类复用同一套 dialog 骨架。整屏覆盖层（用户设置 / 服务器设置）互斥，且与所有浮层互斥。

**色板集中且可切换**：所有颜色来自 `ui/theme.rs::palette`，且都是带括号的函数调用（`palette::bg_chat()`），深/浅两套值写在同一个 token 表里；视图里禁止裸写色值。

项目内有一份**开发规范 `agent.md`**，记录目录职责、依赖规则、gpui-kit 0.10 的 API 坑位、各类交互约定与验收清单。任何新增功能都应先读它再动手。

## 已知限制

- **无后端**：没有服务端与多端同步，只有本机 JSON 快照（路径见「数据与存储」）；删除该文件即恢复种子数据
- **权限位只是演示配置**：13 项权限可切换继承 / 允许 / 拒绝并写入快照与审核日志，但不校验任何真实操作（消息发送、频道访问等不受影响）
- **无真实文件**：附件选择器是模拟清单，图片卡是占位色块，不读取磁盘、不上传
- **通话是演示态**：私信语音/视频只切换界面状态，不采集麦克风、摄像头或屏幕内容
- **GIF 是演示占位**：搜索面板与消息卡用色块 + emoji 字形模拟动图，不加载真实 GIF 资源
- **主题只有两套**：深色 / 浅色是手工调过的两套值，「跟随系统」只在点选时读一次窗口外观，系统外观在运行中变化不会自动跟随
- **帮助中心是本地文档**：12 篇说明是静态文案，不联网、不随代码自动生成
- **好友分组只是本地展示顺序**：不支持拖拽排序与跨设备同步，分组折叠状态不写入快照（重启后全部展开）
- **邀请链接是本地生成的**：不联网校验，使用次数与剩余时间都是快照里的演示字段，不会随时间真正推进
- **成员管理只影响本地列表**：昵称、移出、封禁都写在本机快照里，不会真的阻止某人重新加入，也不和任何后端校验
- **审核日志只记本机操作**：记录的是本应用内的变更（不读系统日志），时间按「中间隔了几次操作 × 1 分钟」推算，不是真实时间戳；超过 200 条丢最旧的
- **自动审核是纯本地关键词匹配**：只检查当前输入的文字（大小写不敏感，不做语义理解），仅在服务器频道生效；规则保存在本机快照，不上传、不跨设备同步
- **投票是本地模拟**：投票者名单写在消息上并进快照，但只有"你"能真实操作；其他人（含种子里的票数）是演示数据，不会有人真的投票，也不跨设备同步
- **日程是本地演示**：活动状态由「距开始多少分钟」推算、不随真实时钟推进；报名只改本地名单，不会真的提醒或跨设备同步
- **消息请求是本地模拟**：请求由种子预置，没有真实的陌生人消息推送；接受仅在本机建立私信会话、忽略/删除只改本地状态，不跨设备同步
- **通知设置只影响应用内聚合**：级别只决定侧栏角标样式与是否进收件箱，没有系统通知 / 移动端推送（应用本身不采集系统通知权限）；「静音服务器」等价于把服务器默认级别设为「关闭通知」，原本的「仅 @提及」会被重置为「全部消息」
- 头像为「首字 + 颜色」生成，不加载真实图片
