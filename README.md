# discordGpui

用 **Rust + gpui-kit** 手写的一个 Discord 风格桌面 IM 界面。

目标是把 Discord 桌面端的界面与交互完整复刻一遍：不复用任何现成 UI 框架的皮肤，所有布局、弹层、菜单、状态都在这套代码里显式实现。**纯前端 Demo，数据为内存中的模拟数据，没有后端、没有持久化**，但分层刻意做成可替换结构，方便日后接真实 API。

## 界面布局

```text
+--------+----------------+--------------------------+---------------+
| Rail   | Channels / DMs | Chat                     | Members       |
+========+================+==========================+===============+
| [1]    | TEXT CHANNELS  | # general                | ADMIN - 3     |
| [2]    |   # general    |   topic + tools          |   Nova        |
| [3]    |   # frontend   |   ---------------------  |   Kai         |
|        | VOICE          |   messages (grouped)     | MODERATOR - 2 |
| [@]    |   voice room   |   ---------------------  |   Lin         |
| [o]    |                |   composer: @mention     | ONLINE - 4    |
+========+================+==========================+===============+
| user bar: avatar / name / status / mic / headphones / settings     |
+----------------------------------------------------------------------+
```

服务器栏底部还有两个独立入口：**私信主页**（好友 + 会话列表）与**探索页**（发现并加入公开服务器）。

## 功能一览

### 服务器与频道

| 能力 | 说明 |
| --- | --- |
| 服务器切换 | 左侧栏点击切换，徽标取名字首字、颜色可改 |
| 新建服务器 | 服务器栏 `+` → 输入名称 → Enter/创建，建完自动切入 |
| 新建频道 | 分类标题 `+` 或服务器菜单入口 → 输入名称 → 建完自动切换，同名拦截 |
| 分类管理 | 新建 / 重命名 / 删除分类，右键菜单操作，空分类保留 |
| 分类折叠 | 点分类标题折叠展开，状态跟随服务器隔离 |
| 频道右键菜单 | 标记为已读、编辑频道主题、删除频道（至少保留一个文字频道） |
| 服务器下拉菜单 | 服务器设置、邀请好友、静音、标记服务器已读、创建频道、离开服务器 |

### 聊天

| 能力 | 说明 |
| --- | --- |
| 消息发送 | Enter 发送，自动滚动到底，支持只发附件 |
| 消息分组 | 同一作者连续消息紧凑展示（`.grouped()`） |
| 表情回应 | 点击回应计数 +1/-1，自己的回应高亮 |
| 消息操作菜单 | 编辑（仅自己）、置顶 / 取消置顶、复制文本、删除 |
| 行内编辑 | 编辑态直接改原文，Enter 保存、Esc/取消放弃 |
| 附件消息 | 附件选择器（5 个模拟文件）→ 待发附件条 → 图片占位卡 / 文件卡 |
| @提及 | 输入 `@` 弹出成员补全浮层，提及在正文中高亮可点击开资料卡 |
| 表情选择器 | 可以给消息加回应，也可以把表情追加到输入框末尾 |
| 就地搜索 | 标题栏搜索框过滤当前会话消息 |
| 搜索中心 | 放大镜进入，跨频道 / 私信检索，范围 chips（当前服务器 / 全部服务器 / 私信 / 全部），命中高亮，点击结果直达 |
| 置顶面板 | 标题栏图钉打开，列出当前会话置顶消息，可取消置顶 |
| 收件箱 | 标题栏 Inbox 带未读角标，聚合提及 / 未读 / 私信 / 好友请求，点击跳转并标记已读 |
| 时间戳 / Emoji 尺寸 / 紧凑模式 | 用户设置里开关，消息区实时生效 |

### 好友与私信

- 好友页五个标签：**在线 / 待处理 / 全部 / 已屏蔽 / 添加好友**
- 待处理请求可接受（加入好友列表并移除请求）或拒绝，重名会拦截
- 添加好友：`用户名#标签` 输入 → 发送 → 自动跳到待处理标签
- 好友行可屏蔽，屏蔽后进「已屏蔽」分组，可取消屏蔽
- 私信侧栏真实搜索（过滤会话 + 好友 + 发起新对话），点好友即建会话并切入

### 成员

- 成员栏按角色分组（管理员 / 版主 / 在线 / 离线），分组可折叠，成员数实时统计
- 点成员或消息作者 → 右侧资料卡（头像、状态、角色、简介、一键「发消息」）
- **右键成员** → 上下文菜单：查看资料卡、发送私信、在输入框提及、复制用户名、屏蔽 / 取消屏蔽

### 语音

- 点语音频道即连接，底部状态条常驻（跨视图保持），再点断开
- 状态条点击展开**语音房间面板**：自己与 3 位参与者、逐个静音 / 移出、本机麦克风开关、断开
- 频道 / 分类 / 服务器被删除时语音状态与参与者列表一并清理

### 探索页

- 服务器栏底部指南针进入，整屏浏览公开服务器
- 关键词搜索 + 分类 chips（游戏 / 科技 / 设计 / 音乐 / 学习 / 影视 / 全部）
- 「加入」后服务器直接出现在左侧栏并自动进入，已加入的卡片显示「已加入」

### 设置

**用户设置**（底部齿轮，8 个分类）：账户、隐私与安全、外观、声音与视频、通知、文字与图片、快捷键、语言。
含主题模式选择、各开关、音量加减、恢复默认；`show_timestamps` / `show_emoji` / `compact_messages` 会真正影响消息渲染。

**服务器设置**（服务器菜单 → 服务器设置，4 个分类）：
- **概览**：改名（消息记录与分类折叠状态自动迁移）、改简介、6 色徽标切换
- **角色**：按角色汇总成员与人数
- **表情**：移除 / 恢复服务器表情
- **邀请**：邀请链接复制（按钮变「已复制」）、打开邀请弹层

## 快速开始

环境要求：**macOS** + Rust 工具链（2024 edition，需 1.85+）。

```bash
git clone https://github.com/zhangli344236745/discordGpui.git
cd discordGpui
cargo run
```

首次构建需要编译 gpui 全家桶，耗时较长；之后增量构建在 10 秒内。

窗口固定为 1440×900，标题 `Discord UI · GPUI Kit`，默认深色主题。

```bash
cargo check   # 类型检查，保持 0 error / 0 warning
cargo build   # 完整构建
```

> 本机 `rustfmt` 未安装，`cargo fmt` 会报 `cargo-fmt is not installed`；需要格式化先 `rustup component add rustfmt`。

## 项目结构

```text
src/
├── main.rs              # 应用初始化、主题、窗口配置
├── app.rs               # DiscordApp：全部状态 + 业务方法 + 顶层渲染分发
├── data/
│   ├── models.rs        # 纯数据模型（Server/Channel/Message/Member/Friend/Attachment/...）
│   └── seed.rs          # 模拟数据工厂
└── ui/
    ├── theme.rs         # 统一色板 palette + ico()
    ├── widgets.rs       # 可复用组件：avatar / unread_badge
    ├── server_rail.rs   # 服务器栏
    ├── channel_sidebar.rs / dm_sidebar.rs / friends.rs / member_list.rs
    ├── discover.rs      # 探索页
    ├── settings/        # 用户设置页（mod / sidebar / pages）
    ├── server_settings/ # 服务器设置页（mod / sidebar / pages）
    ├── search_center.rs # 搜索中心
    ├── voice_status.rs / voice_room.rs
    ├── *_menu.rs *_dialog.rs  # 各类右键菜单与模态弹层
    └── chat/            # 聊天区：header / messages / composer /
                         #   emoji_picker / attachment_picker / message_menu /
                         #   pinned_panel / inbox_panel
```

43 个 Rust 文件、约 1.1 万行代码，全部手写布局。

## 设计要点

**分层与依赖方向**

```text
main → app → data
        ↓
       ui（各视图 render 函数）
```

- `data/` 纯模型，不引用 `app` 或 `ui`，可直接替换为真实 API 响应
- `app.rs` 集中所有状态与业务方法（改状态 + `cx.notify()`），视图只读状态、调方法
- `ui/` 每个模块导出一个 `pub fn render(app, cx)`，不持有自身状态

**状态与视图的边界**：写操作一律是 `DiscordApp` 上的动词方法（`send_message` / `select_channel` / `toggle_*` / `open_*`），视图里不出现字段变更逻辑。这样每个交互都是「视图发出 → app 改状态 → 重渲染」的单向闭环。

**浮层统一约定**：菜单类用绝对定位卡片 + 全屏透明遮罩（点外部关闭），锚点分「跟随光标」与「贴标题栏」两种；模态类复用同一套 dialog 骨架。整屏覆盖层（用户设置 / 服务器设置）互斥，且与所有浮层互斥。

**色板集中**：所有颜色来自 `ui/theme.rs::palette`，禁止裸写色值 —— 深色主题下改一处即可全局生效。

项目内有一份**开发规范 `agent.md`**，记录目录职责、依赖规则、gpui-kit 0.10 的 API 坑位、各类交互约定与验收清单。任何新增功能都应先读它再动手。

## 已知限制

- **无后端**：所有数据在内存里，重启应用恢复种子数据；消息、改名、屏蔽等改动不持久化
- **无真实文件**：附件选择器是模拟清单，图片卡是占位色块，不读取磁盘、不上传
- **主题只做了深色**：外观页的「浅色 / 跟随系统」仅记录选择，色板仍是常量（尚未拆成主题变量）
- **少数入口仍是静态图标**：输入框旁的礼物按钮、标题栏帮助按钮暂未接交互
- 消息操作目前走悬停省略号按钮，尚未接右键（成员 / 频道 / 分类已经支持右键）
- 头像为「首字 + 颜色」生成，不加载真实图片
