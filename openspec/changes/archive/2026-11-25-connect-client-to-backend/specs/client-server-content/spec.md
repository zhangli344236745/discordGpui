# Spec Delta

## Purpose

定义服务器设置、成员治理、内容工具与检索通知在客户端上的真实写路径，保证界面显示的权限、列表与计数都以服务端结果为准。

## ADDED Requirements

### Requirement: 服务器设置与模板

服务器设置页 SHALL 通过 `/servers` CRUD、`/templates`、`/templates/apply`、`/order` 修改名称、简介、徽标色、模板与排序。成功后 MUST 以响应更新本地状态；失败 MUST 保留原值并提示原因。

#### Scenario: 修改服务器简介

- **WHEN** 管理员保存简介
- **THEN** 概览与服务器头部立即显示新简介，刷新后仍保持

#### Scenario: 重名

- **WHEN** 创建服务器时名称与已有服务器重复
- **THEN** 显示 409 提示，不创建本地服务器

#### Scenario: 模板应用

- **WHEN** 管理员选择模板并应用
- **THEN** 分类/频道/欢迎配置按模板重建，界面同步刷新

### Requirement: 成员、角色与权限矩阵

客户端 SHALL 通过成员/角色/权限/频道覆盖/封禁端点执行管理操作。所有写操作 MUST 先按本地权限隐藏或禁用入口，但仍以服务端 403 为准；收到后 MUST 回滚并提示缺少的权限。

#### Scenario: 无权限入口

- **WHEN** 当前用户没有 `MANAGE_ROLES`
- **THEN** 角色页保存按钮禁用并显示原因

#### Scenario: 服务端拒绝

- **WHEN** 用户绕过本地限制提交角色修改，服务端返回 403
- **THEN** 界面回滚到修改前状态并提示缺少的权限位

#### Scenario: 频道覆盖生效

- **WHEN** 管理员 deny 某角色 `VIEW_CHANNEL`
- **THEN** 具有该角色的成员下次刷新/收到 `PERMISSIONS_UPDATE` 后看不到该频道

### Requirement: 邀请与加入

客户端 SHALL 创建、列出、撤销、预览与接受邀请。邀请列表 MUST 显示过期/用尽/已撤销状态；接受被封禁的邀请 MUST 显示服务端错误，不加入服务器。

#### Scenario: 创建邀请

- **WHEN** 用户选择有效期与次数上限
- **THEN** 返回邀请码并出现在邀请管理列表，可复制

#### Scenario: 接受邀请

- **WHEN** 用户打开有效邀请链接并接受
- **THEN** 服务器出现在侧栏，欢迎屏幕按配置弹出

#### Scenario: 失效邀请

- **WHEN** 邀请已过期或用尽
- **THEN** 预览显示失效原因，接受按钮禁用

### Requirement: 审核与自动审核

客户端 SHALL 管理自动审核规则并查看审核日志。规则保存后 MUST 立即影响后续发送；日志 MUST 支持类别筛选与游标加载，清空仅 owner 可见。

#### Scenario: 新增拦截规则

- **WHEN** 管理员保存 block 关键词规则
- **THEN** 之后发送命中词返回错误提示，消息不出现在频道

#### Scenario: 审核日志筛选

- **WHEN** 管理员选择「角色」类别
- **THEN** 列表只显示角色类日志，滚动可加载更早记录

### Requirement: 内容工具

客户端 SHALL 支持论坛帖子/回帖/置顶/锁定、投票、话题、日程报名、欢迎屏幕、加成与书签的端点调用。锁定帖子 MUST 隐藏回帖输入；投票结束后 MUST 禁止改票；这些状态以服务端响应或事件为准。

#### Scenario: 锁定帖子

- **WHEN** 版主锁定帖子并收到更新
- **THEN** 所有客户端隐藏回帖输入，尝试回帖显示无权限

#### Scenario: 投票结束

- **WHEN** 发起人结束投票
- **THEN** 选项变为只读，结果保留并显示已结束

#### Scenario: 加成

- **WHEN** 用户点击加成
- **THEN** 侧栏加成条与设置页等级同步更新，撤销后回落

### Requirement: 搜索与通知

客户端 SHALL 调用 `/search`、频道内搜索与 `/search/suggest`，并把结果跳转到正确会话；通知页 SHALL 使用 `/notifications` 与 `/read`，未读数来自 `/unread-counts`。搜索 MUST 只展示后端返回的可见结果。

#### Scenario: 搜索跳转

- **WHEN** 用户点击跨频道搜索结果
- **THEN** 客户端切换到目标服务器/频道并定位到该消息 id

#### Scenario: 标记通知已读

- **WHEN** 用户点击收件箱通知
- **THEN** 调用已读接口，角标按服务端结果减少

#### Scenario: 无权结果

- **WHEN** 用户已失去某频道查看权限
- **THEN** 搜索与通知中不再出现该频道内容

### Requirement: 分页与增量加载

消息、帖子、审核日志、通知与搜索结果 MUST 使用游标分页。用户滚动到顶部/底部时加载更多，不得重复插入同一 id，也不得因加载失败清空已有列表。

#### Scenario: 加载更早消息

- **WHEN** 用户滚动到消息列表顶部
- **THEN** 请求 `before` 游标并前插更早消息，顺序正确

#### Scenario: 加载失败

- **WHEN** 分页请求失败
- **THEN** 保留已有消息并显示可重试提示
